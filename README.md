# weatherstack
Pulling the latest weather information for a city from weatherstack's API.

You can sign up for the free Weather Stack API [here.](https://weatherstack.com/)

### Steps to Pulling Data

For now, you can:
1. Clone the repo
2. Sign up for an API key from Weather Stack.
3. Export your API key locally `export API_KEY="your-api-key-here"`
4. `cd src` into the src folder, then run `python read_api.py`

As of now, you can change the city location within the `read_api.py` script.
